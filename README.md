# SQL Business Sales Analysis

## Project Overview
This project uses SQL to analyze a sample sales dataset and answer business questions about revenue, profitability, product performance, and regional sales.

## Tools
- SQL
- SQLite

## Dataset
The dataset contains 10 sample sales records with order IDs, product names, categories, regions, sales amounts, profit, and quantities.

## Analysis Performed
- Calculated total revenue, profit, and quantity sold.
- Compared sales performance across products.
- Analyzed revenue and profit by region.
- Calculated each product's percentage contribution to revenue.
- Identified orders above the average order value.
- Ranked orders by sales amount using a window function.
- Compared average order value across products.

## Business Value
The queries demonstrate how SQL can summarize sales data, identify high-performing products and regions, and support business decisions.

## How to Run
1. Open a SQLite-compatible SQL editor.
2. Execute the table creation and data insertion statements in `sales_analysis.sql`.
3. Run the analysis queries to view the results.

## Limitations
This project uses a small, self-created sample dataset for learning and demonstration. Results are illustrative and do not represent an actual company's performance.
